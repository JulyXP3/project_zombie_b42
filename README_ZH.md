# Project Zomboid B42 - EtherHack 社区构建版

面向 Project Zomboid Build 42 的 [EtherHack 3.1.0 (B42)](https://github.com/dei0/EtherHack) 社区维护构建。

在原版基础上新增了 **耕种 / 地图传送 + 汽车传送 / 载具导航模式(沿道路网自动行驶) / 点亮全图 / 真-夜视 / 战斗强化 + 临时武器 / 战利品重掷 + 物品生成(物品生成 (MP) · 尸体生成 · 计时生成) / ESP / 物品雷达 + 小地图标记** 等大量功能, 并针对 B42 客户端 Lua 环境 (Kahlua) 做了多处修复与加固。完整功能见下方「功能一览」。

> **重要声明:** 本项目**禁止任何形式的商业用途**(包括售卖、付费下载等), 二次修改与转载**必须标注原作者**。授权条款详见文末「许可证」。

## 功能一览

界面: 赛博朋克风图标+文字磁贴导航, 中/英/俄三语即时切换, 菜单关闭后恢复上次页面与滚动位置; 菜单键与各项快捷键可在「设置」页改绑。以下按导航页分组:

### 信息

- 反作弊状态(权限反作弊 / 移动反作弊 / 自定义日志系统 / BikiniTools 可用性)、注意事项、作者与联系方式

### 生存

- **物品与携带**: 自动修理背包中的物品 / 无限负重
- **状态与需求**: 无限耐力 / 高速回血(不是无敌) / 禁用肌肉拉伤 / 状态与需求全系禁用(疲劳/饥饿/口渴/醉酒/愤怒/恐惧/疼痛/恐慌/士气低落/压力/疾病/吸烟压力/理智/无聊/不快乐/潮湿/感染/虚假感染) / 维持最佳卡路里 / 维持最佳体重 / 修复身上衣物 / 身上衣物填充皮革条
- **调试权限功能(仅单人)**: 上帝模式 / 穿墙模式 / 隐身模式 / 进度条秒走完 —— 需先在「其他」页开启「解锁调试权限(单人)」
- **特殊模式**: 创造模式 / 夜视模式 / **真-夜视**(渲染级全亮, 夜色与视野锥黑幕移除, 无灯室内不再漆黑, 纯客户端) / 僵尸不会攻击玩家(多人可用)

### 战斗

- **战斗强化**: 攻速倍率(1~2.5) / 攻击距离加成(0~4) / 秒杀模式 / 暴击Max / 枪械只爆头(必爆头, 3 倍伤害) / 枪械百发百中(无视环境) / 群攻 / 提高枪械射速 / 无限弹药(耗尽自动补满, 可设弹药数) / 无卡壳
- **超级群攻**: 每次挥击命中上限 10~20(可攻击以自身为中心的全部敌人; 伤害被平均分摊, 故单只伤害偏低, 可配合暴击Max/秒杀模式)
- **临时武器**: 本地生成枪械替换手持(全枪械列表搜索 + 临时替换/取消替换)

### 物品(SP)

- **物品创建**: 名称/类别/ID 过滤, 一键给予 x1/x2/x5/x10

### 物品雷达

- 全物品库列表(名称/ID 搜索) + 「在地图上显示」+「ESP 画线追踪」(三处状态与小地图「物品」快捷按钮双向同步)

### 陷阱

- **模式切换**: 食物 / 武器; 搜索 + 点击生成(食物: 站在已放置的陷阱旁; 武器: 陷阱自动放在脚下并自动拾取, 每件需数秒); 数量可循环

### 交换

- 用背包中的**衣物/背包**当祭品, 一件一换指定目标物品(目标与祭品双列表, 均带名称/ID 搜索)

### 玩家

- **玩家信息 & 配方**: 编辑存活时间 / 编辑击杀僵尸数 / 学习所有可用的制作配方
- **VHS教学**: 可训练技能列表(搜索) + 升级所选技能 / 全技能升级(需附近有开着且音量 5 以上的收音机/电视/车载收音机, 没有时自动把背包里的设备摆出来; 每技能 30 秒冷却, XP 上限默认 3 级随服务器配置而定)
- **角色特性**: 特性添加/移除; **技能**: 技能等级 ± / 添加经验 / 所有技能升满

### ESP

- 总开关 + 四模块: 玩家信息(附近玩家用户名、主/副手物品)、载具信息(马力/极速)、僵尸信息(头顶血条、僵尸雷达)、独立功能(玩家雷达 150 格、载具雷达、视野 360 度)

### 地图

- **点亮全图**: 一键揭示全部未知区域(多人下服务端同步记录)
- **右键菜单**(M 大地图与面板/小地图一致): 快速移动(沿可行走路径滑行, 17 格/秒, 不触发移动反作弊, 距离不限)、快速移动(穿墙)、**汽车传送**(坐在驾驶位时显示: 连人带车分跳推进至目标点, 单跳步长受服务器限速预算约束, 支持直接跨越水面)、导航前往此处 / 清除导航线 / 继续导航
- 小地图: 可移动窗口 + 快捷开关栏, 显示本机玩家/其他玩家/僵尸/载具/物品

### 战利品

- **重置战利品(F9)**: 半径可调(默认 10), 重置后打开容器重新生成战利品(可反复刷枪柜/弹药箱, 仅多人)
- **刷弹药**: 按弹匣/枪械类型生成弹药
- **物品生成 (MP)**: 主手装备鱼竿后可将列表中任意物品生成进背包(约 5~8 秒入包; 生成失败会在服务端留下日志; 仅多人)
- **尸体生成**: 在脚下生成一具携带指定物品的尸体, 搜尸取物(仅多人; **会在服务器上留下日志, 请谨慎使用**)
- **计时生成**: 走游戏自身的取物动作生成**真实物品**(可持久化、他人可见), 带「加速」开关控制生成速度(仅多人)

### 载具

- **引擎与启动**: 无条件启动引擎(单次 / 自动重试, 成功即自动取消; 引擎能否启动仍需油/电)
- **维修与补给**: 修理车辆(用本车后备箱/手套箱/座椅里的物品当令牌, 默认不消耗; 每步头顶提示) / 直发修理(立即满件, 每件在服务端留一行日志) / 加满油
- **远程上车**: 自己上车(20 米内最近载具的司机座) / 把最近的其他在线玩家塞进其附近载具的司机座(仅多人)
- **导航模式**: 沿道路网自动开往终点 —— 上驾驶位打火后按 M 打开地图右键「导航前往此处」即出发; 行驶中再锚定 = 改道; 巡航速度自适应或指定(受服务端限速硬顶钳制); 按任意驾驶键当帧接管, 到达/下车/引擎熄火自动结束

### 耕种

- **作物管理**: 范围(格) N×N 可调(默认 3×3), 生长进入下一阶段 / 直接成熟(可收获) / 浇水到满 / 清空水分 / 全部治病 / 感染病害+25 / 收获 / 铲除 / 移除残骸; 状态行实时计数并区分残骸/空地; 生长类操作最晚在下一个游戏 10 分钟刻生效
- **播种**: 全种子列表名称/ID 搜索, 免农具翻土 / 免种子播种 / 在周围已翻土上播种, 播后自动浇水

### 趣味

- **冒名发消息**: 指定频道(全服 / 说话 30 格)与冒名对象后发送(被冒名者本人看不到该条)
- **僵尸皮肤**: 烂脸 / 重度腐烂 / 轻度腐烂 / 恢复皮肤

### 创建角色

- **自定义编辑**: 建号时自由添加/删除特性(可搜索列表, 点击加入/移出)、自定义技能等级(0..10); 名单持久化
- **建号增强**: 建号全特性 / 建号技能满级 / 解锁全部服装(建号界面显示游戏原生全服装选择器, 建号时自由穿搭) / 角色特性点数(滑块调节)
- 所有效果在点击"创建"瞬间生效; 创建前取消勾选即回退

### 其他

- 解锁调试权限(单人) / 服务器同步保护(防止属性与技能被服务端回滚) / 管理员菜单(8 型)与尝试获取管理员权限(12 型) / 调试菜单(主)·游戏调试菜单·车辆机械菜单·医疗菜单 / 发放所选配方的所有材料 / 禁止执行默认日志记录器 / 禁止执行提及作弊的文件 / 禁止执行含可疑词的文件

### 设置

- 界面语言(中/英/俄) / 按键绑定(独立子面板) / 强调色 / 玩家·载具·僵尸 UI 元素渲染颜色 / 配置列表(保存/加载/删除/重载) / 重载所有 Lua 元素 / 重置默认设置

## 安装

环境要求: **JDK 25** 与 **Gradle 9.1.0**。构建通过内置的 Gradle wrapper(`gradlew.bat`)执行, 首次运行会自动下载 Gradle; 也可使用本机已安装的 Gradle。

1. 准备编译依赖: 将游戏根目录下的 `projectzomboid.jar` 复制到 `etherhack-src/lib/` 目录下, 并改名为 `zombie.jar`(该文件仅用于编译, 不会被修改)。
2. 打开 `etherhack-src/build.bat`, 填写好 `JAVA_HOME`, 保存之后运行 `build.bat`。
3. 从 `build` 目录中拿到 `modcore-3.2.5-B42.jar`。
4. 将 jar 和 `etherhack-src/install.bat`(以及可选的 `etherhack-src/uninstall.bat`)一起复制到游戏根目录。
5. 运行 `install.bat` 完成安装。

安装成功后会**自动删除 jar**。卸载有两种方式：① 目录里**没有** `modcore-*.jar` 时再运行 `install.bat`(合并脚本会自动进入卸载模式)；② 直接运行 `uninstall.bat`(独立卸载脚本, 随时可用, 与 jar 是否在目录里无关)。两者都会删掉注入的 `zombie\`、`modcore\` 与 `%USERPROFILE%\Zomboid\modcore.bin`, 不会碰游戏本体。切勿删除 `projectzomboid.jar`——那是游戏本体。

游戏中按 **Insert** 打开 EtherHack 面板。

## 从源码构建

环境要求: JDK 25, 已包含 Gradle wrapper。

```bat
cd etherhack-src
gradlew.bat jar
```

产物在 `etherhack-src/build/modcore-3.2.5-B42.jar`。Lua 源码嵌入在 `src/main/resources/modcore/lua/` 中, 构建时自动打包。

## 已知限制

- **过滤是纯子串匹配**(名称/ID, 不区分大小写): 未选中任何物品就勾选「在地图上显示」或「ESP 画线追踪」, 会追踪过滤列表里的**全部**物品, 例如搜索 `Wrench` 会连 `Ratchet Wrench` 一起追踪。只想追踪单个物品, 请先在列表中选中它。
- 物品雷达只能扫描玩家周围 56 格内**已加载**的区块(客户端限制; 服务端的 `processItems` 注册表在客户端恒为空), 且刷新有节流: 背包变动防抖 1 秒后重扫, 移动时走出 5 格且距上次扫描 ≥4 秒才重扫, 命中位置不是逐帧实时。
- 刻意不扫描玩家背包/身上装备; 其他玩家的物品有 1~2 秒同步延迟。
- 服务器开启战利品加密后, 客户端完全看不到容器内容。
